# Datasets

Place the benchmark files directly in this folder (for example `dataset/ETTh1.csv`).

| File | Dataset | Source |
|---|---|---|
| `ETTh1.csv`, `ETTh2.csv` | ETT (hourly) | [Autoformer Google Drive](https://drive.google.com/drive/folders/1ZOYpTUa82_jCcxIdTmyr0LXQfvaM9vIy) |
| `electricity.csv` | Electricity | same Google Drive |
| `traffic.csv` | Traffic | same Google Drive |
| `weather.csv` | Weather | same Google Drive |
| `solar_AL.txt` | Solar-Energy | [LSTNet data repository](https://github.com/laiguokun/multivariate-time-series-data) (`solar-energy/solar_AL.txt.gz`, unzip it) |

The data are not redistributed here; please follow the terms of the original sources.
